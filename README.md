# SaaS Intel Hub

Full-stack data application for exploring Micro-SaaS ideas with ML insights.

[![CI](https://github.com/ndumbe0/saas-intel-hub/actions/workflows/ci.yml/badge.svg)](https://github.com/ndumbe0/saas-intel-hub/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## Features
- Search, filters, facets for SaaS ideas
- ML: revenue prediction, clustering, tactic analysis
- Data ingestion and bring-your-own-data
- Interactive dashboards with Recharts
